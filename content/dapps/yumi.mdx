## About Yumi

Yumi is a credit-as-a-service platform built on stablecoin rails. Rather than building a consumer-facing lending app, Yumi provides the SDK and API for neobanks, payment gateways, and fintech apps to embed credit products into their existing workflows.

On Fluent, Yumi uses Prints reputation as one of the signals for underwriting — combining wallet history, on-chain behavior, and additional verified data sources to underwrite unsecured loans without requiring collateral upfront.

## Why this matters

Most crypto lending is over-collateralized, meaning you can only borrow if you already have more than you want to borrow. That's useful for leverage but doesn't function as real credit. Yumi targets the gap: actual unsecured credit, underwritten by reputation rather than collateral.

The team builds onchain credit profiles from loan history, repayment behavior, and reputation signals — turning DeFi from a leverage tool into actual financial infrastructure.
